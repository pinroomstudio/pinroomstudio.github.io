Pin ROOM Studio プライバシーポリシー

日本語

Pin ROOM Studio は、運営者が自分自身のPinterestアカウントのためだけに使うコンテンツ管理ツールです。Pinterestから受け取る情報は、運営者のPinの作成と、そのPinの成果確認にのみ使用し、販売・広告利用・第三者への提供は行いません。

1. このアプリについて

Pin ROOM Studio（以下「本アプリ」）は、インテリアや生活便利グッズに関するオリジナル画像と説明文を作成し、運営者が1件ずつ確認・承認したうえで、Pinterest API を通じて運営者自身のボードにPinとして投稿するためのツールです。本アプリは運営者のパソコン上で動作し、一般には提供していません。

2. Pinterestから取得する情報

運営者がPinterestの公式認可画面（OAuth）で許可した範囲で、次の情報を取得します。Pinterestのパスワードを本アプリが受け取ることはありません。

情報利用目的保存
アクセストークン・リフレッシュトークンPinterest API を利用するため暗号化（AES-256-GCM）して保存
アカウント名（ユーザー名）接続中のアカウントを画面に表示するため保存
ボードの一覧投稿先ボードを選ぶため保存しない（表示のたびに取得）。選んだボードのIDと名前のみ保存
本アプリで作成したPinのID投稿履歴の管理のため保存
運営者のPinの分析指標（インプレッション、保存数、Pinクリック数、外部リンククリック数）コンテンツの成果確認と改善のため保存

要求する権限：boards:read, boards:write, pins:read, pins:write, user_accounts:read。他のユーザーのPin・ボード・フォロワー情報は取得しません。

3. 情報の保存場所と管理

  • 情報は運営者のパソコン内のデータベースにのみ保存し、外部のサーバーには保存しません。
  • トークンは暗号化して保存し、ログや画面に表示しません。
  • APIキーなどの認証情報はソースコードに含めず、運営者のパソコン内の設定ファイルで管理します。

4. 第三者への提供

取得した情報を販売したり、広告目的で利用したり、第三者に提供したりすることはありません。ただし、次の外部サービスを利用します。

  • Pinterest：Pinの作成と分析データの取得のため、Pinterest API と通信します。
  • OpenAI：画像と文章を生成するため、運営者が入力した商品情報を OpenAI API に送信します。また、改善提案を作成するため、運営者のPinの集計結果（タイトル、カテゴリー、インプレッション数などの合計値）を送信することがあります。アクセストークンやアカウントの認証情報は送信しません。

5. Cookie・トラッキング

本アプリは、広告やアクセス解析のためのCookie・トラッキング技術を使用しません。

6. 保存期間と削除

  • 本アプリの「接続を解除」を実行すると、保存したトークンを削除します。
  • Pinterestの設定画面（アプリの接続管理）から、いつでも本アプリへのアクセス許可を取り消せます。
  • 投稿履歴と分析指標は、運営者がコンテンツ改善に使う間保存し、不要になった時点で削除します。

7. 本ポリシーの変更

内容を変更する場合は、このページを更新し、制定日・更新日を記載します。

English

Pin ROOM Studio is a content management tool used only by its operator for the operator's own Pinterest account. Information received from Pinterest is used only to create the operator's Pins and to review their performance. It is never sold, used for advertising, or shared with third parties.

1. About this app

Pin ROOM Studio ("the App") creates original images and descriptions about home interior and useful household items. The operator reviews and approves each Pin individually before it is published to the operator's own board through the Pinterest API. The App runs on the operator's own computer and is not offered to the public.

2. Information we receive from Pinterest

The App receives only the information the operator authorizes on Pinterest's official OAuth consent screen. The App never receives the operator's Pinterest password.

InformationPurposeStorage
Access token and refresh tokenTo call the Pinterest APIStored encrypted (AES-256-GCM)
Account usernameTo show which account is connectedStored
List of boardsTo choose the board to publish toNot stored (fetched each time). Only the selected board's ID and name are stored
IDs of Pins created by the AppTo keep a publishing historyStored
Analytics for the operator's own Pins (impressions, saves, Pin clicks, outbound clicks)To review and improve content performanceStored

Requested scopes: boards:read, boards:write, pins:read, pins:write, user_accounts:read. The App does not access other users' Pins, boards, or follower information.

3. Where information is stored

  • Information is stored only in a database on the operator's own computer, not on external servers.
  • Tokens are stored encrypted and are never shown in logs or on screen.
  • API keys and credentials are kept in a local configuration file, not in source code.

4. Sharing with third parties

We do not sell information, use it for advertising, or share it with third parties. The App uses these external services:

  • Pinterest: to create Pins and retrieve analytics through the Pinterest API.
  • OpenAI: product information entered by the operator is sent to the OpenAI API to generate images and text. Aggregated performance figures for the operator's own Pins (titles, categories, and totals such as impressions) may be sent to generate improvement suggestions. Access tokens and account credentials are never sent.

5. Cookies and tracking

The App does not use cookies or tracking technologies for advertising or analytics.

6. Retention and deletion

  • Selecting "Disconnect" in the App deletes the stored tokens.
  • Access can be revoked at any time from Pinterest's settings (connected apps).
  • Publishing history and analytics are kept while the operator uses them to improve content, and deleted when no longer needed.

Any changes will be posted on this page with an updated date.
